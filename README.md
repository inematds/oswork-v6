# OSWork — Organize seu ambiente de IA (edição v6)

Curso do INEMA.CLUB PRO para quem já usa um chat de IA de vez em quando e quer parar de improvisar.
Sete aulas de uns 15 minutos: pastas por assunto, ficha de orientação, molde de pedido e rotina de conferência.
Sem instalar nada. Abra `landing.html` ou `curso.html#trilha` — funciona offline e guarda o progresso no navegador.
